### Hi, I'm Audrey

I'm a data scientist in Harare, working on mobile money data at Ecocash. Most of my day is Python and R: figuring out what customers are doing, why, and how to explain that to people who don't want to read a notebook.

Lately I've been moving toward the ops side, keeping systems healthy as well as analysing them, so expect some AIOps and cloud work here too.

**Projects**

- [mobile-money-churn](https://github.com/DreyMuch/mobile-money-churn): predicting which wallet customers are about to go quiet, and scoring the model by how many of them a retention team can actually reach
- [transaction-forecasting](https://github.com/DreyMuch/transaction-forecasting): 4 week transaction forecasts that know about payday, Zimbabwean public holidays and tariff changes
- [server-metrics-anomalies](https://github.com/DreyMuch/server-metrics-anomalies): incident detection on API metrics, comparing static thresholds, seasonal z-scores and isolation forests

The data in these repos is simulated, since I can't publish real customer data, but it's built to behave like the real thing.

**Tools I use:** Python (pandas, scikit-learn, statsmodels), R (tidyverse, ggplot2), SQL, Git
